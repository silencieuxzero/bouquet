# 题型一：地方时与区时计算

## 题目1：基础地方时计算

**题目**：已知北京（116°E）的地方时为10:00，求乌鲁木齐（87°E）的地方时。

**解释**：地方时因经度不同而不同。乌鲁木齐在北京西侧，经度更小，地方时更晚。

**解题方法**：
1. 计算经度差：116° − 87° = 29°
2. 换算时间差：29° × 4分钟/度 = 116分钟 = 1小时56分钟
3. 确定方向：乌鲁木齐在北京西侧，用减法（东加西减）
4. 计算结果：10:00 − 1:56 = **8:04**

> **关键要点**：所求地在已知地东侧用加法，西侧用减法；经度差同为东经或西经用减法，一东一西用加法。

---

## 题目2：区时计算（跨越东西时区）

**题目**：当北京时间（东8区）为7月30日14:00时，纽约（西5区）的区时是什么？

**解释**：区时计算需要考虑时区差，纽约与北京不在同一时区，且跨越东西时区。

**解题方法**：
1. 计算时区差：8 + 5 = 13（一东一西，时区序号相加）
2. 确定方向：西5区在东8区的西侧，用减法
3. 计算区时：14:00 − 13:00 = 1:00
4. 日期不变（未跨过24点）：7月30日 **1:00**

> **关键要点**：一东一西时区差相加；计算结果若大于24则加一天，小于0则减一天。

---

## 题目3：飞行时间计算

**题目**：某飞机从北京（东8区）当地时间7月30日8:00起飞，飞行10小时后到达伦敦（零时区），求到达时伦敦的当地时间。

**解释**：需要先计算起飞时的伦敦时间，再加上飞行时间。

**解题方法**：
1. 计算起飞时伦敦时间：8:00 − 8小时 = 7月30日 **0:00**
2. 加上飞行时间：0:00 + 10小时 = 7月30日 **10:00**

> **关键要点**：先换算目的地时间再加飞行时长；或先加飞行时长再换算（结果相同）。

---

## 题目4：时区推断

**题目**：某地地方时为12:00时，北京时间（120°E）为16:00，求该地的经度。

**解释**：地方时比北京时间晚4小时，说明该地在120°E的西侧。

**解题方法**：
1. 计算时间差：16:00 − 12:00 = 4小时
2. 换算经度差：4小时 × 15°/时 = 60°
3. 确定方向：该地时间更晚（数值更小），在120°E的西侧
4. 计算结果：120°E − 60° = **60°E**

> **关键要点**：时间"早"（数值大）的经度更东；时间每差1小时，经度差15°。

# 题型二：昼夜长短的判断与计算

## 题目5：昼夜长短的季节变化

**题目**：6月22日（夏至日），下列城市中白昼最长的是？A. 哈尔滨（45°N） B. 北京（40°N） C. 上海（31°N） D. 广州（23°N）

**解释**：夏至日太阳直射北回归线，北半球纬度越高白昼越长。

**解题方法**：
1. 确定日期特征：夏至日，北半球昼最长夜最短，且纬度越高白昼越长
2. 比较选项中各城市的纬度：
   - 哈尔滨（45°N）纬度最高
   - 北京（40°N）
   - 上海（31°N）
   - 广州（23°N）纬度最低
3. 结论：纬度最高的**哈尔滨**白昼最长，选 **A**

> **关键要点**：夏至日北半球昼长随纬度升高而增长；冬至日相反。

---

## 题目6：昼夜长短计算

**题目**：某地日出时间为北京时间5:20，该地经度为120°E，求该地的昼长和日落时间。

**解释**：日出日落时间与昼长有固定换算关系，前提是使用当地地方时。由于该地在120°E，北京时间就是当地地方时。

**解题方法**：
1. 方法一（对称法）：
   - 日落时间 = 12 + (12 − 5:20) = 12 + 6:40 = **18:40**
   - 昼长 = 18:40 − 5:20 = **13小时20分钟**
2. 方法二（直接法）：
   - 昼长 = (12 − 5:20) × 2 = 6:40 × 2 = **13小时20分钟**
   - 日落时间 = 5:20 + 13:20 = **18:40**

> **关键要点**：日出时间 + 昼长 = 日落时间；日出到正午 = 正午到日落；若给出的日出时间是北京时间而非地方时，需先换算。

## 题目7：南北半球昼夜长短对称性

**题目**：已知北纬60°在夏至日的昼长为18小时30分，求南纬60°在夏至日的昼长。

**解释**：南北半球同纬度昼夜长短呈对称关系——北半球某纬度的昼长等于南半球同纬度的夜长。

**解题方法**：
1. 北纬60°夏至日昼长 = 18小时30分
2. 南纬60°夏至日的夜长 = 北纬60°昼长 = 18小时30分
3. 南纬60°夏至日昼长 = 24小时 − 18小时30分 = **5小时30分**

> **关键要点**：同一日期，北半球某纬度的昼长 = 南半球同纬度的夜长。

---

## 题目8：根据昼夜长短判断纬度

**题目**：甲地昼长14小时，乙地昼长10小时，丙地昼长12小时。三地按纬度从高到低排序正确的是？

**解释**：纬度越高，昼夜长短的变化幅度越大（与赤道12小时的差值越大）。

**解题方法**：
1. 计算各昼夜长与12小时的差值：
   - 甲：|14 − 12| = 2小时
   - 乙：|10 − 12| = 2小时
   - 丙：|12 − 12| = 0小时
2. 差值越大，纬度越高
3. 甲和乙差值相同，说明它们纬度相等（一个在北半球，一个在南半球）
4. 丙的差值为0，在赤道
5. 排序：**甲 = 乙 > 丙**

> **关键要点**：昼长偏离12小时越多，纬度越高；赤道全年昼夜等长（12小时）。

# 题型三：正午太阳高度的计算与应用

## 题目9：正午太阳高度计算

**题目**：求夏至日时北回归线（23°26′N）的正午太阳高度。

**解释**：夏至日太阳直射北回归线，直射点处的正午太阳高度应为90°。

**解题方法**：
1. 确定夏至日太阳直射点纬度：δ = 23°26′N
2. 当地纬度：φ = 23°26′N
3. 计算纬度差：|23°26′ − 23°26′| = 0°
4. 代入公式：H = 90° − 0° = **90°**
5. 验证：直射点处正午太阳高度为90°，合理

> **关键要点**：太阳直射点所在纬度的正午太阳高度为90°；公式 H = 90° − |φ − δ|。

---

## 题目10：正午太阳高度比较

**题目**：冬至日，北京（40°N）、广州（23°N）、悉尼（34°S）三地正午太阳高度从大到小排序。

**解释**：冬至日太阳直射南回归线（23°26′S），距直射点越近正午太阳高度越大。

**解题方法**：
1. 冬至日直射点：δ = 23°26′S
2. 计算各纬度与直射点的纬度差：
   - 北京：|40° − (−23°26′)| = |40° + 23°26′| = 63°26′
   - 广州：|23° − (−23°26′)| = |23° + 23°26′| = 46°26′
   - 悉尼：|34°S − 23°26′S| = 10°34′（同为南半球，用减法）
3. 纬度差越小，正午太阳高度越大
4. 排序：**悉尼（最大）> 广州 > 北京（最小）**

> **关键要点**：正午太阳高度取决于距直射点的纬度距离，距直射点越近越大；同半球纬度差用减法，异半球用加法。

---

## 题目11：楼间距计算

**题目**：北纬36°34′某住宅小区，前楼高34米，为保证一楼全年都能被阳光照射，楼间距至少应为多少米？（cot 30° ≈ 1.73，cot 36°34′ ≈ 1.35）

**解释**：北半球楼间距应以**冬至日**的正午太阳高度为基准计算，因为冬至日是一年中正午太阳高度最小、日影最长的日子。

**解题方法**：
1. 计算冬至日该地的正午太阳高度：
   - 冬至日直射点 δ = 23°26′S
   - H = 90° − |36°34′ − (−23°26′)| = 90° − 60° = **30°**
2. 计算最小楼间距：
   - 楼间距 ≥ 前楼高度 × cot H
   - 楼间距 ≥ 34 × cot 30° = 34 × 1.73 ≈ **58.8米**

> **关键要点**：北半球用冬至日的正午太阳高度（日影最长）；南半球用夏至日（当地冬至日）。

---

## 题目12：太阳能热水器倾角

**题目**：北京（40°N）在冬至日时，太阳能热水器的集热板与地面的最佳倾角是多少？

**解释**：太阳能热水器集热板的最佳倾角应使太阳光线垂直于集热板，此时吸收效率最高。

**解题方法**：
- 方法一（倾角 = 纬度差）：
  1. 冬至日直射点 δ = 23°26′S
  2. 倾角 α = |40° − (−23°26′)| = 63°26′
- 方法二（倾角 = 90° − H）：
  1. 计算冬至日正午太阳高度：H = 90° − 63°26′ = 26°34′
  2. 倾角 α = 90° − 26°34′ = 63°26′

两种方法结果一致：**63°26′**

> **关键要点**：太阳能倾角 = 当地纬度与直射点纬度的差值 = 90° − 正午太阳高度。

---

## 题目13：日影长度与方向判断

**题目**：夏至日正午，北京（40°N）的日影方向是？一年中日影最长的一天是？

**解释**：正午日影方向与正午太阳方位相反；日影长度与正午太阳高度成反比。

**解题方法**：
1. **日影方向**：
   - 北回归线以北，正午太阳始终在正南方
   - 日影方向与太阳方位相反，故日影始终**朝北**
2. **日影最长的一天**：
   - 日影最长 → 正午太阳高度最小
   - 北京（北回归线以北），冬至日正午太阳高度最小
   - 因此日影最长的一天是**冬至日**

> **关键要点**：北回归线以北正午日影始终朝北，南回归线以南始终朝南；日影长度与正午太阳高度成反比。

# 题型四：晨昏线判读

## 题目14：晨昏线识别

**题目**：在下面的光照图（侧视图）中，判断AB线是晨线还是昏线。

```
       太阳光线  →  →  →
                 ________
               /|        |\
             /  |        |  \
           /    |        |    \
         /    A |        | B   \
       /        |________|       \
      |  夜半球  |  昼半球   |
      |          |           |
```

**解释**：顺地球自转方向，从夜半球进入昼半球的是晨线，从昼半球进入夜半球的是昏线。

**解题方法**：
1. 确定地球自转方向：自西向东（在侧视图上一般从左向右）
2. 判断A到B的过渡：
   - A点：在夜半球一侧
   - B点：在昼半球一侧
   - 顺自转方向（A→B），从夜半球进入昼半球
3. 结论：AB线为**晨线**

> **关键要点**：自转方向法是最可靠的晨昏线判读方法——由夜→昼为晨线，由昼→夜为昏线。

---

## 题目15：光照图综合判读

**题目**：右图为某日光照图（侧视图），北极圈内出现极昼，回答：
（1）该日是哪一节气？
（2）太阳直射点的坐标是？
（3）北京时间是多少？

**解释**：北极圈内极昼→夏至日；直射点纬度=北回归线；经度=昼半球中央经线。

**解题方法**：
1. **判断节气**：
   - 北极圈内出现极昼 → 夏至日（6月22日前后）
2. **求直射点坐标**：
   - 纬度：直射北回归线 23°26′N
   - 经度：昼半球中央经线的地方时为12:00，即为直射点所在经线
3. **求北京时间**：
   - 找到图中已知时间（如晨线与赤道交点所在经线为6:00，昏线与赤道交点为18:00）
   - 根据经度差推算120°E的区时

> **关键要点**：北极圈极昼→夏至；南极圈极昼→冬至；晨赤交点6:00，昏赤交点18:00。

# 题型五：太阳直射点移动与日期推断

## 题目16：太阳直射点移动方向判断

**题目**：10月1日国庆节时，太阳直射点位于哪个半球？正在向哪个方向移动？

**解释**：10月1日介于秋分（9月23日前后）和冬至（12月22日前后）之间。

**解题方法**：
1. **确定所在区间**：
   - 9月23日（秋分）→ 12月22日（冬至）
   - 10月1日在此区间内
2. **判断半球**：
   - 秋分时直射赤道，冬至时直射南回归线
   - 此时太阳直射点在南半球
3. **判断移动方向**：
   - 从赤道向南回归线移动
   - 移动方向为**向南**

> **关键要点**：春分→夏至直射点向北移动；夏至→秋分向南；秋分→冬至向南；冬至→春分向北。

## 题目17：日期范围计算

**题目**：当北京时间为7月30日10:00时，全球处于7月30日的范围占全球的比例是多少？

**解释**：全球日期分界线有两条——国际日期变更线（大致180°经线）和地方时0:00经线。

**解题方法**：
1. **求0:00经线的经度**：
   - 北京时间（120°E）为10:00
   - 0:00经线与120°E的时间差 = 10小时
   - 经度差 = 10小时 × 15°/时 = 150°
   - 0:00经线在120°E的西侧（时间更晚）
   - 0:00经线 = 120°E − 150° = **30°W**
2. **确定7月30日的范围**：
   - 从30°W（0:00）向东到180°（国际日期变更线）
   - 跨经度 = 180° − (−30°) = 180° + 30° = 210°
3. **计算比例**：
   - 比例 = 210° ÷ 360° = **7/12**

> **关键要点**："今天"的范围 = 从0:00经线向东到180°经线；0:00经线向东到180°跨多少度，今天就占全球的多少。

## 题目18：国庆节昼夜长短分析

**题目**：国庆节（10月1日）期间，下列叙述正确的是：
A. 北京昼长夜短
B. 南极地区出现极昼
C. 太阳直射点在南半球，向北移动
D. 太阳直射点在南半球，向南移动

**解释**：10月1日介于秋分（9月23日）和冬至（12月22日）之间，直射点在南半球且向南移动。

**解题方法**：
1. **分析各选项**：
   - A：10月1日北半球昼短夜长，北京也不例外 → **错误**
   - B：南极极昼出现在冬至日前后，10月初南极尚未出现极昼 → **错误**
   - C：直射点在南半球，但秋分→冬至期间直射点向南移动，不是向北 → **错误**
   - D：直射点在南半球且向南移动 → **正确**
2. 答案：**D**

> **关键要点**：秋分→冬至（9月~12月）：直射点在南半球，向南移动；北半球昼短夜长，且昼渐短、夜渐长。

# 题型六：地转偏向力

## 题目19：河流侵蚀与堆积

**题目**：北半球一条自西向东流的河流，哪一岸受冲刷更严重？如果要在河岸建港口，应选哪一岸？

**解释**：地转偏向力使北半球水平运动的物体向右偏，河流水向右岸偏转。

**解题方法**：
1. **判断偏转方向**：
   - 北半球河水向右偏
   - 河流自西向东流，右岸为南岸
2. **判断冲刷/堆积**：
   - 右岸（南岸）：河水偏转冲刷，水深，适合作港口
   - 左岸（北岸）：泥沙沉积，水浅
3. **答案**：
   - 南岸（右岸）冲刷更严重
   - 港口应选在**南岸**

> **关键要点**：北半球河流右岸侵蚀、左岸堆积；港口建在侵蚀岸（水深），淘金在堆积岸。

---

## 题目20：台风旋转方向

**题目**：北半球和南半球的台风（热带气旋）分别呈什么旋转方向？

**解释**：台风是低压中心，气流受地转偏向力影响形成气旋式旋转。

**解题方法**：
1. **北半球**：
   - 低压中心气流向中心辐合
   - 受地转偏向力影响向右偏
   - 整体呈**逆时针**方向旋转
2. **南半球**：
   - 同样向中心辐合
   - 受地转偏向力影响向左偏
   - 整体呈**顺时针**方向旋转

> **关键要点**：北半球台风逆时针旋转，南半球顺时针旋转（记忆：北逆南顺）；高压系统旋转方向相反。

# 题型七：正午太阳方位与物影

## 题目21：太阳能集热板一年中的调整

**题目**：北京（40°N）的太阳能热水器集热板，在一年中与地面的最小夹角和最大夹角分别是多少？

**解释**：集热板倾角 = 当地纬度与直射点纬度的差值。当直射点最靠近北京时倾角最小，最远离时倾角最大。

**解题方法**：
1. **最小倾角**（夏至日，直射点最靠近北京）：
   - δ = 23°26′N，α = |40° − 23°26′| = **16°34′**
2. **最大倾角**（冬至日，直射点最远离北京）：
   - δ = 23°26′S，α = |40° − (−23°26′)| = **63°26′**
3. **调整范围**：一年中需要在16°34′到63°26′之间调整，幅度为46°52′

> **关键要点**：太阳能集热板倾角变化范围 = 2倍黄赤交角（46°52′）；夏至日倾角最小，冬至日倾角最大。

## 题目22：房屋采光问题

**题目**：北纬30°某地建一栋朝南的房子，为使所有楼层全年都能晒到太阳，前后楼间距至少要保持多少？已知前楼高40米，冬至日正午太阳高度为36°34′（cot 36°34′ ≈ 1.35）。

**解释**：北半球房屋朝南采光最好，楼间距以冬至日的日影长度为基准。

**解题方法**：
1. **计算冬至日日影长度**：
   - 日影长 = 楼高 × cot H = 40 × cot 36°34′ = 40 × 1.35 = **54米**
2. **结论**：
   - 前后楼间距至少需要 **54米**
   - 小于此距离时，后排低层在冬至日前后无法被阳光照射

> **关键要点**：北半球以冬至日正午太阳高度计算最小楼间距；若题目未给出H，先用公式 H = 90° − |φ − δ| 计算。

# 题型八：综合读图题

## 题目23：日照图的综合判读

**题目**：已知下图中AB为晨线，完成下列各题。

```
       太阳光线  ↓  ↓  ↓
                 ________
               /|        |\
             /  |        |  \
           /    |        |    \
```

（1）此日为北半球的什么节气？
（2）D点的地方时是？
（3）C点的昼夜长短情况？

1. **判断节气**：

   - D点与C点的经度差 → 时间差 → 地方时
3. **求C点昼夜长短**：
   - C在赤道上 → 全年昼夜等长（各12小时）

> **关键要点**：晨赤交点6:00；昏赤交点18:00；昼半球中央经线12:00；夜半球中央经线0:00。

## 题目24：从日出日落方位推断地点

**题目**：某地全年均在北京时间6:00日出，18:00日落，该地最可能位于？

**解释**：全年昼夜等长、日出日落时间固定，说明该地在赤道上。但北京时间6:00日出对应当地地方时6:00，说明当地经度与120°E相同。

**解题方法**：
1. **分析昼夜特征**：
   - 全年6:00日出、18:00日落 → 全年昼夜等长
   - 只有**赤道**上全年昼夜等长（12小时）
2. **分析经度**：
   - 日出时间为北京时间6:00，对应当地地方时6:00
   - 说明当地时间与北京时间相同
   - 该地位于120°E经线上
3. **结论**：该地位于**赤道与120°E的交点**附近

> **关键要点**：全年昼夜等长→赤道；日出时间与北京时间一致→当地经度=120°E。

# 题型九：极昼极夜问题

## 题目25：极昼极夜范围

**题目**：当太阳直射北纬20°时，发生极昼的纬度范围是？

**解释**：极昼极夜的边界纬度与太阳直射点的纬度互余。

**解题方法**：
1. **极昼极夜边界公式**：
   - 极昼/极夜边界纬度 = 90° − 太阳直射点纬度
2. **计算**：
   - 90° − 20° = 70°
3. **确定范围**：
   - 北半球极昼：**北纬70°以北（含70°N ~ 90°N）**
   - 南半球极夜：**南纬70°以南（含70°S ~ 90°S）**

> **关键要点**：直射点在北半球时，北极附近出现极昼，南极附近出现极夜；切点纬度 = 90° − 直射点纬度。

## 题目26：极昼地的正午太阳高度

**题目**：在北极点上，夏至日的正午太阳高度是多少？

**解释**：北极点位于90°N，夏至日太阳直射23°26′N。

**解题方法**：
1. 代入公式：H = 90° − |90° − 23°26′| = 90° − 66°34′ = **23°26′**
2. 验证：北极点夏至日太阳高度角在一天中几乎不变（极昼），始终约为23°26′

> **关键要点**：极点处太阳高度角变化极小，极昼期间太阳高度角 = 直射点纬度（同半球）或 90° − 极点到直射点的纬度差。

# 题型十：跨日和日期变更

## 题目27：国际日期变更线的应用

**题目**：一艘轮船于7月30日12:00从东12区向西航行，30分钟后进入西12区，此时轮船上的日期和时间是？

**解释**：自东向西越过国际日期变更线（从东12区到西12区），日期加一天。

**解题方法**：
1. 时间变化：
   - 航行30分钟 → 时间增加30分钟 → 12:30
2. 日期变化：
   - 从东12区自东向西越过日界线进入西12区
   - 日期**加一天**
3. 结果：**7月31日12:30**

> **关键要点**：东12区→西12区（自东向西过日界线）：日期+1天；反之日期−1天。口诀"东减西加"。

## 题目28：两条日期界线的综合应用

**题目**：已知阴影部分表示7月30日，非阴影部分表示7月31日。求此时北京时间。

```
       180°
    ┌───────┐
    │       │
    │ 阴影  │
    │       │
    ├───────┤ ← 0:00经线
    │       │
    │非阴影 │
    │       │
    └───────┘
        0°
```

**解题方法**：
1. 两条日界线：180°（固定）和0:00经线（可变）
2. 已知阴影为7月30日，非阴影为7月31日
3. 从0:00经线向东到180°为"今天"（7月31日）
4. 从180°向东到0:00经线为"昨天"（7月30日）
5. 根据图中比例推算0:00经线的经度
6. 再求120°E的区时（北京时间）

> **关键要点**：这类题目的突破口是确定0:00经线的位置；从0:00经线向东到180°是今天，向西到180°是昨天。

# 附录：解题方法总结

## 常用公式速查

| 公式 | 适用场景 |
|------|----------|
| **H = 90° − \|φ − δ\|** | 正午太阳高度计算 |
| **纬度差 = \|当地纬度 − 直射点纬度\|** | 正午太阳高度简化计算 |
| **所求地方时 = 已知地方时 ± 经度差 × 4分钟/度** | 地方时计算（东加西减） |
| **所求区时 = 已知区时 ± 时区差** | 区时计算（东加西减） |
| **昼长 = 日落 − 日出** | 昼夜长短计算 |
| **日出 = 12 − 昼长/2** | 由昼长求日出时间 |
| **日落 = 12 + 昼长/2** | 由昼长求日落时间 |
| **时区 = 经度 ÷ 15°（余数≥7.5时商+1）** | 由经度求时区 |
| **中央经线 = 时区数 × 15°** | 由时区求中央经线 |
| **楼间距 ≥ 楼高 × cot H** | 楼间距计算（H为冬至日正午太阳高度） |
| **太阳能倾角 = \|φ − δ\|** | 太阳能集热板最佳倾角 |
| **极昼边界 = 90° − 直射点纬度** | 极昼极夜范围判断 |

## 核心思维方法

1. **画图法**：光照图、时区图、晨昏线图——遇到抽象问题先画图
2. **对称法**：利用南北半球对称、时间对称简化计算
3. **特殊点法**：找赤道（6:00/18:00）、直射点（12:00）、切点（0:00/12:00）
4. **口诀法**：北逆南顺、北右南左、东加西减、东减西加
5. **排除法**：选择题先排除明显违背基本规律的选项

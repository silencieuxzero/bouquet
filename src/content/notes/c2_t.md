# 题型一：岩石圈物质循环

## 题目1：三大类岩石的转化

**题目**：读岩石圈物质循环示意图，回答：
（1）图中甲、乙、丙分别代表哪类岩石？
（2）①~④分别代表什么地质作用？

```
        ┌─── ① ───→  乙
        │                │
        │                ③
        │                ↓
    ┌───┤           ┌───────┐
    │   │           │   丙   │
    │   │           └───────┘
    │   │                ↑
    │   └─── ④ ───→      │
    │                     │
    │   ┌───────┐        ②
    └──→   甲   ──────────┘
        └───────┘
```

**解释**：岩石圈物质循环中，岩浆只能转化为岩浆岩，三大类岩石可相互转化，所有岩石均可重熔为岩浆。

**解题方法**：
1. **确定甲**：只有岩浆能直接冷却形成岩浆岩，甲为**岩浆**
2. **确定乙**：甲（岩浆）→①→乙，①为冷却凝固，乙为**岩浆岩**
3. **确定丙**：乙可转化为丙，丙也可转化为乙，丙为**变质岩**或**沉积岩**，需结合箭头方向判断
4. **确定作用**：
   - ①：冷却凝固
   - ②：外力作用（风化、侵蚀、搬运、堆积、压实固结）或变质作用
   - ③：变质作用或外力作用
   - ④：重熔再生

> **关键要点**：岩浆是岩石圈物质循环的源头和归宿；岩浆岩只能由岩浆冷却形成；三大类岩石均可转化为岩浆。

## 题目2：岩石特征判断

**题目**：某岩石具有层理构造，且含有三叶虫化石，该岩石属于哪类岩石？可能是什么岩石？

**解释**：层理构造和化石是沉积岩的典型特征。

**解题方法**：
1. **分析特征**：
   - 层理构造 → 沉积岩的典型特征
   - 含有化石 → 只能出现在沉积岩中（岩浆岩和变质岩的高温高压环境会破坏化石）
2. **判断岩石类型**：**沉积岩**
3. **进一步判断**：含三叶虫化石，形成于古生代海洋环境，可能为**石灰岩**（生物化学沉积）或**页岩**（细粒碎屑沉积）

> **关键要点**：化石只存在于沉积岩中；层理构造是沉积岩的鉴别特征；岩浆岩有气孔构造、矿物结晶；变质岩有片理构造。

---

## 题目3：岩浆岩特征应用

**题目**：某地发现一种岩石，呈灰黑色，有气孔构造，质地坚硬。该岩石最可能是？它属于哪类岩石？其形成条件是什么？

**解释**：气孔构造是喷出岩（火山岩）的典型特征，是岩浆喷出地表时气体逸出留下的孔洞。

**解题方法**：
1. **分析特征**：
   - 灰黑色 → 基性岩特征（富含铁镁矿物）
   - 气孔构造 → 喷出岩（岩浆喷出地表，气体迅速逸出）
   - 质地坚硬 → 总体仍坚硬
2. **判断岩石**：**玄武岩**
3. **分类**：**岩浆岩中的喷出岩**
4. **形成条件**：岩浆喷出地表 → 迅速冷却 → 气体逸出形成气孔

> **关键要点**：气孔构造 = 喷出岩（玄武岩）；矿物结晶粗大 = 侵入岩（花岗岩）；层理+化石 = 沉积岩；片理 = 变质岩。

# 题型二：背斜与向斜的判读

## 题目4：根据岩层新老关系判断构造

**题目**：读某地质剖面图，岩层由老到新依次为①②③④，图中甲处岩层向上拱起，乙处岩层向下弯曲，但甲处为谷地，乙处为山岭。判断甲、乙分别是什么地质构造？解释为什么会形成这种地形。

```
    甲（谷地）       乙（山岭）
    ┌──────┐        ┌──────┐
    │ ④新  │        │ ④新  │
    │ ③    │  ──┐  │ ③    │
    │ ②    │ /  │  │ ②    │
    │ ①老  │/   │  │ ①老  │
    └──────┘    │  └──────┘
                 │
            ──── ┘
   （甲岩层向上凸，乙岩层向下凹）
```

**解释**：不能仅根据地貌判断背斜和向斜，需依据岩层新老关系。

**解题方法**：
1. **分析岩层形态**：
   - 甲处岩层向上拱起 → 形态上像背斜
   - 乙处岩层向下弯曲 → 形态上像向斜
2. **根据岩层新老关系确认**：
   - 甲处：核部岩层老（①），两翼岩层新（②③④）→ **背斜**
   - 乙处：核部岩层新（④），两翼岩层老（①②③）→ **向斜**
3. **解释地形倒置**：
   - 甲（背斜）：顶部受张力 → 岩石破碎 → 易被侵蚀 → 形成谷地（**背斜谷**）
   - 乙（向斜）：槽部受挤压 → 岩石坚硬 → 不易被侵蚀 → 残留成山岭（**向斜山**）

> **关键要点**：判读背斜和向斜的最可靠方法 = **岩层新老关系**（背斜核老翼新，向斜核新翼老）；地貌不可靠（存在地形倒置）。

## 题目5：背斜向斜的实践应用

**题目**：某地区计划修建一条东西向的隧道，现有两条路线方案：甲路线经过背斜，乙路线经过向斜。从地质角度分析，应选择哪条路线？

**解释**：隧道工程应选择背斜，因为背斜岩层受张力作用，稳定性好，且不易积水。

**解题方法**：
1. **分析背斜建隧道的优势**：
   - 背斜为**拱形结构**，岩层受张力，顶部较稳定（拱形结构力学性能好）
   - 背斜顶部不易积水（水向两侧渗流）
   - 岩石破碎（张力作用下）→ 易于开挖
2. **分析向斜建隧道的劣势**：
   - 向斜槽部**受挤压**，开挖时易发生岩层变形和坍塌
   - 向斜是**良好的储水构造**，隧道内易积水
3. **结论**：应选择甲路线（经过**背斜**）

> **关键要点**：隧道选背斜（安全、不积水）；水库选背斜（不漏水）；石油天然气在背斜顶部聚集（油气轻，向上运移）。

---

## 题目6：找矿找水

**题目**：甲地为背斜，乙地为向斜，如果在该地区寻找石油天然气应选哪里？寻找地下水应选哪里？

**解释**：石油天然气比水轻，向上运移到背斜顶部聚集；水重在向斜槽部汇集。

**解题方法**：
1. **找石油天然气**：
   - 选**甲（背斜）**
   - 原因：石油、天然气密度小，沿岩层向上运移，在背斜顶部聚集形成油气藏
2. **找地下水**：
   - 选**乙（向斜）**
   - 原因：地下水密度大，沿岩层向下渗流，在向斜槽部汇集形成地下水储集层

> **关键要点**："背斜油汽，向斜水"；背斜是储油构造，向斜是储水构造。

# 题型三：断层的判读与应用

## 题目7：断层类型判断

**题目**：下图为某地质剖面图，图中岩层发生了断裂，其中A侧岩块相对上升，B侧岩块相对下降。请问该断层属于什么类型？图中C处地貌是什么？

```
        A                  B
    ┌────┐             ┌────┐
    │    │             │    │
    │    │  ↑ 上升     │    │  ↓ 下降
    │    │             │    │
    └────┘             └────┘
    ─────────────────────────── 断层面
```

**解释**：判断断层类型需看相对位移方向。上升的为地垒或上盘上升（逆断层），下降的为地堑或上盘下降（正断层）。

**解题方法**：
1. **判断断层类型**：
   - 岩层断裂且有明显位移 → **断层**
   - A侧上升、B侧下降 → 正断层（上盘相对下降）或逆断层（上盘相对上升）
   - 需根据断层面的倾向确定上盘和下盘
   - 如果断层面如图倾斜，B侧在断层面之上（上盘）→ 上盘下降 → **正断层**
2. **判断C处地貌**：
   - C处（上升盘）常形成**陡崖**或**断块山**
   - C处可能形成**断层崖**（断层三角面）

> **关键要点**：正断层（张力→上盘下降）常形成谷地；逆断层（压力→上盘上升）常形成山岭；地垒（两条正断层之间上升）→块状山；地堑（两条正断层之间下降）→谷地或湖泊。

## 题目8：断层的实践应用

**题目**：某地计划修建一座大型水库，勘测发现库区存在一条活断层。请从地质角度分析在该地修建水库是否合理。

**解释**：断层带地质条件不稳定，不适宜修建大型水利工程。

**解题方法**：
1. **分析断层建库的风险**：
   - **渗漏**：断层带岩石破碎、裂隙发育 → 库水沿断层渗漏
   - **诱发地震**：水库蓄水增加地壳压力 → 可能诱发断层活动 → 引发地震
   - **滑坡、崩塌**：断层带岩体破碎 → 库岸不稳定 → 易发生滑坡和崩塌
   - **溃坝风险**：坝基不稳 → 影响大坝安全
2. **结论**：不合理。应**避开断层带**选择坝址
3. **理想坝址条件**：
   - 地质构造稳定（避开断层）
   - 岩层坚硬完整
   - 选在背斜（岩层呈拱形，稳定性好）

> **关键要点**：水库、核电站等大型工程必须避开断层带；断层带是地震多发区。

## 题目9：地垒与地堑

**题目**：渭河平原和华山同位于陕西省，华山挺拔险峻，渭河平原地势低平。从地质构造角度解释两者的成因关系。

**解释**：华山和渭河平原是同一断层作用形成的差异地貌——地垒和地堑。

**解题方法**：
1. **分析地质构造**：
   - 华山：属于**地垒**（两条正断层之间岩块相对上升）
   - 渭河平原：属于**地堑**（两条正断层之间岩块相对下降）
2. **形成过程**：
   - 该地区受到张力作用 → 发生断层
   - 中间岩块上升 → 华山（断块山）
   - 相邻岩块下降 → 渭河平原（地堑谷地）
3. **地貌特征**：
   - 华山：悬崖峭壁、山势险峻
   - 渭河平原：地势平坦、土层深厚（黄土堆积）

> **关键要点**：地垒常形成块状山地（华山、庐山、泰山）；地堑常形成谷地或湖泊（渭河平原、汾河谷地、东非大裂谷）。

# 题型四：板块构造与地貌

## 题目10：板块边界判断

**题目**：喜马拉雅山和东非大裂谷分别位于什么板块边界？分别属于什么类型的地貌？

**解释**：喜马拉雅山位于消亡边界（陆陆碰撞），东非大裂谷位于生长边界（板块张裂）。

**解题方法**：
1. **喜马拉雅山**：
   - **板块位置**：亚欧板块与印度洋板块的**消亡边界**
   - **边界类型**：陆陆碰撞型消亡边界
   - **形成过程**：印度洋板块向北俯冲（碰撞）→ 亚欧板块抬升 → 地壳增厚 → 形成山脉
   - **地貌类型**：**褶皱山系**
2. **东非大裂谷**：
   - **板块位置**：非洲板块内部的**生长边界**
   - **边界类型**：大陆张裂型生长边界
   - **形成过程**：板块张裂 → 地壳变薄 → 断裂下陷 → 形成裂谷
   - **地貌类型**：**大陆裂谷**
   - **演化趋势**：裂谷→海洋（类似红海的演化过程）

> **关键要点**：生长边界→海岭/裂谷（张裂）；消亡边界→山脉/海沟/岛弧（碰撞/俯冲）；板块内部稳定，交界处活跃。

## 题目11：火山地震带分布

**题目**：环太平洋地区为什么多火山地震？请用板块构造学说解释。

**解释**：环太平洋地区位于板块消亡边界，地壳活动剧烈。

**解题方法**：
1. **板块位置**：
   - 太平洋板块与周围的亚欧板块、美洲板块、印度洋板块、南极洲板块之间的**消亡边界**
2. **形成原因**：
   - 太平洋板块（大洋板块）向周围大陆板块下方**俯冲**
   - 俯冲带岩石摩擦、挤压 → 应力积累 → 释放 → **地震**
   - 俯冲的大洋板块熔融 → 岩浆上升 → 喷出地表 → **火山**
3. **典型特征**：
   - 全球约80%的地震和75%的火山发生于此
   - 形成"环太平洋火山地震带"（"火环"）

> **关键要点**：全球两大火山地震带——环太平洋带（80%）、地中海-喜马拉雅带（15%）；板块消亡边界是火山地震的主要分布区。

## 题目12：板块运动与海洋演化

**题目**：有人预测红海将会变成一个新的大洋，而地中海将会消失。用板块构造学说解释这一预测的依据。

**解释**：红海位于生长边界，正在扩张；地中海位于消亡边界，正在缩小。

**解题方法**：
1. **红海（生长边界）**：
   - 位于非洲板块与印度洋板块（阿拉伯板块）之间的**生长边界**
   - 板块**张裂** → 地壳变薄 → 海底扩张
   - 未来：裂谷→狭窄海洋→大洋（与东非大裂谷相连）
2. **地中海（消亡边界）**：
   - 位于亚欧板块与非洲板块之间的**消亡边界**
   - 非洲板块向北俯冲到亚欧板块之下
   - 未来：海域→缩小→消失→形成山脉（如阿尔卑斯山的继续隆升）
3. **证据**：
   - 红海：海底扩张、热流值高、地震活动
   - 地中海：深度大、地震频繁、海底沉积物变形

> **关键要点**：生长边界→海洋扩大（红海）；消亡边界→海洋缩小（地中海）；板块运动是地球表面形态演化的根本动力。

# 题型五：外力作用与河流地貌

## 题目13：河流不同河段的地貌特征

**题目**：简述河流从上游到下游的主要地貌特征变化及其原因。

**解释**：河流在不同河段的外力作用主导类型不同，形成不同的地貌特征。

**解题方法**：

| 河段 | 主导作用 | 地貌特征 | 原因 |
|------|----------|----------|------|
| **上游** | 下蚀、溯源侵蚀为主 | V形谷、峡谷、瀑布、急流 | 地势落差大，流速快，向下切割强烈 |
| **中游** | 侧蚀为主，堆积增强 | 河曲（曲流）、河漫滩、阶地 | 地势趋缓，侧蚀加强，河道弯曲 |
| **下游** | 堆积为主 | 三角洲、冲积平原、河口沙洲 | 流速最慢，泥沙大量沉积 |

> **关键要点**：上游下蚀（加深）、中游侧蚀（加宽）、下游堆积（填平）；侵蚀→搬运→堆积呈现接力关系。

## 题目14：河流凹岸与凸岸

**题目**：读某河流曲流示意图，图中A处河岸陡峭，B处河岸平缓。请判断A和B分别属于凹岸还是凸岸？哪一岸适合建港口？哪一岸适合农耕？

```
        ┌─────────────────┐
        │                 │
     ───┘    ▲ A（陡岸）  └───
   （B缓岸）  │           ☆ 水流方向 →
     ───┐    ▼            ┌───
        │                 │
        └─────────────────┘
```

**解释**：曲流中，凹岸侵蚀、凸岸堆积，形成不同的水深和岸坡条件。

**解题方法**：
1. **识别凹凸岸**：
   - A处：河岸陡峭 → **凹岸**（水流速度快，侵蚀强烈）
   - B处：河岸平缓 → **凸岸**（水流速度慢，泥沙堆积）
2. **判断利用方式**：
   - **建港口**：选A（凹岸），水深，利于船舶停靠
   - **农耕/建房**：选B（凸岸），地势平坦、土壤肥沃

**解题方法**：

## 题目22：钟乳石与石笋的形成

**题目**：溶洞中的石钟乳向下生长，石笋向上生长，两者最终可能连接成石柱。请用化学方程式解释石钟乳和石笋的形成过程。

**解释**：石钟乳和石笋的形成与碳酸钙的溶解-沉淀平衡有关。

**解题方法**：
1. **化学原理**：
   - **溶解过程**（地表水渗入石灰岩）：CaCO₃ + H₂O + CO₂ → Ca(HCO₃)₂（可溶性碳酸氢钙）
   - **沉淀过程**（水滴进入溶洞，CO₂逸出）：Ca(HCO₃)₂ → CaCO₃ ↓ + H₂O + CO₂ ↑
2. **石钟乳形成**：
   - 含Ca(HCO₃)₂的水滴在洞顶悬挂
   - CO₂逸出 → CaCO₃析出沉积 → 向下生长
3. **石笋形成**：
   - 水滴落到洞底
   - CO₂逸出 → CaCO₃析出沉积 → 向上生长
4. **石柱形成**：
   - 石钟乳向下生长 + 石笋向上生长 → 两者相连

> **关键要点**：石钟乳从洞顶向下生长，石笋从洞底向上生长；两者化学成分相同（CaCO₃）；石钟乳+石笋=石柱。

**题目**：读某地地质剖面图，判断下列地质事件发生的先后顺序：①沉积岩层形成 ②岩浆侵入 ③断层形成 ④外力侵蚀

```
     ┌─────────────────────────┐
     │   砂岩（沉积岩）        │
     ├─────────────────────────┤
     │   页岩（沉积岩）        │
     ├──────┬────────┬─────────┤
     │      │  花岗岩 │         │
     │      │（侵入岩）│         │

     │ 石灰岩│        │  石灰岩  │
     │      │        │         │
     └──────┴────────┴─────────┘
      ←── 断层 ──→  （岩层发生错动）
```

**解释**：地质事件先后顺序遵循"先形成的地层在下，后被切断的岩层更老"的原则。

   - **第四步**：**外力侵蚀**（若有侵蚀面则发生在最后）
3. **结论**：①→②→③→④

> **关键要点**："先沉积后构造，岩浆活动看切穿，断层形成在之后"；被切穿的岩层比切穿它的岩层老。

# 题型十：内外力作用的关系

## 题目25：内外力作用的辩证关系

**题目**：喜马拉雅山是世界最高的山脉，但科学家发现它的高度并没有无限增加。请用内外力作用的原理进行解释。

**解释**：喜马拉雅山的高度是内力抬升和外力侵蚀共同作用的结果。

**解题方法**：
1. **内力作用**：
   - 印度洋板块与亚欧板块持续碰撞 → 地壳增厚 → 山体**抬升**
   - 板块碰撞速度约5 cm/年 → 抬升速度约1 cm/年
2. **外力作用**：
   - **风化、侵蚀**：冰川、流水、风力不断侵蚀山体
   - 侵蚀速度与抬升速度逐渐达到**动态平衡**
3. **综合结果**：
   - 当抬升速度 > 侵蚀速度 → 山体增高
   - 当抬升速度 < 侵蚀速度 → 山体降低
   - 当两者速度相近 → 山体高度趋于稳定
   - 喜马拉雅山目前仍以约1 cm/年的速度缓慢抬升（内力占主导）

> **关键要点**：内力作用使地表高低不平（造山），外力作用削高填低（夷平）；地表形态是内外力共同作用的结果。

## 题目26：地貌演化阶段

**题目**：从内外力作用的角度，说明一个山地从形成到最终夷平的过程。

**解释**：地貌演化经历了内力抬升、外力侵蚀、最终夷平的完整过程。

**解题方法**：

| 阶段 | 主导作用 | 地貌特征 |
|------|----------|----------|
| **青年期** | 内力抬升为主 | 山体快速升高，地势陡峭，V形谷发育 |
| **壮年期** | 内力和外力趋于平衡 | 山体高度相对稳定，河谷拓宽，出现曲流 |
| **老年期** | 外力侵蚀为主 | 山体降低，地势起伏减小，形成准平原 |
| **夷平期** | 外力作用持续 | 基本夷平为平坦地面（准平原） |

**完整循环**：
```
内力抬升 → 青年期山地 → 壮年期山地 → 老年期山地 → 准平原
（新一轮内力抬升可能再次开始该循环）
```

> **关键要点**：地貌演化是"内力抬升→外力削平"的动态过程；一个完整的地貌旋回可能持续数百万至数千万年。

1. **自然因素**：

| 因素 | 具体影响 |
|------|----------|
| **地形** | 坡度大、地势起伏大 → 重力作用显著 |
| **地质** | 断层发育、岩层破碎 → 岩体不稳定 |
| **气候** | 降水集中、多暴雨 → 触发滑坡泥石流 |
| **植被** | 自然植被破坏后覆盖率低 → 水土保持能力差 |

2. **人为因素**：

| 活动 | 不良影响 |
|------|----------|
| **过度开垦** | 破坏植被，加剧水土流失 |
| **采矿** | 破坏山体结构，废渣堆积 |
| **修路** | 开挖边坡，形成不稳定坡面 |
| **水库蓄水** | 浸泡坡体，诱发滑坡 |
| **城市扩张** | 削山填谷，改变地表形态 |

3. **防治措施**：
   - 植树造林，恢复植被
   - 修筑护坡、挡土墙等工程措施
   - 合理规划人类活动
   - 建立地质灾害监测预警系统

> **关键要点**：地质灾害 = 自然因素（地形、地质、气候、植被）+ 人为因素（不合理的人类活动）；预防为主，防治结合。

## 核心思维方法

1. **物质循环法**：掌握三大类岩石的转化关系，明确"岩浆→岩浆岩"的唯一性
2. **新老关系法**：利用岩层新老关系判断背斜和向斜，这是最可靠的方法
3. **地质顺序法**：先确定沉积→再确定构造→最后确定岩浆活动和外力作用
4. **内外力辩证分析法**：地表形态 = 内力作用 × 外力作用 × 时间
5. **板块构造法**：全球宏观地貌用板块构造学说解释
6. **比较法**：对比易混概念（冲积扇vs三角洲、地垒vs地堑、U形谷vsV形谷）

# 第一部分：Fandom 平台概述

## 一、认识 Fandom

### 1.1 什么是 Fandom

**Fandom**（原名 Wikia）是全球最大的粉丝社群平台之一，托管着数以百万计的 Wiki 站点。每个 Wiki 围绕一个特定主题（如影视作品、游戏、动漫、音乐等）由粉丝社群共同创建和维护。

Fandom 基于 **MediaWiki** 引擎构建，后者也是 Wikipedia 所使用的开源维基软件。这意味着 Fandom 的编辑语法与 Wikipedia 高度兼容，同时增加了一些面向粉丝社区的专属功能。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **Wiki** | 一个独立的站点，围绕特定主题，如"洛疏律 Wiki" |
| **页面（Page）** | Wiki 中的基本内容单元，每个页面有唯一的标题 |
| **编辑（Edit）** | 修改页面内容的操作 |
| **版本历史（History）** | 每次编辑都会保存版本记录，可回溯或对比差异 |
| **模板（Template）** | 可复用的内容片段，用 `{{模板名}}` 调用 |
| **分类（Category）** | 将相关页面归类的机制 |
| **命名空间（Namespace）** | 页面前缀，区分不同类型页面（如 `模板:`、`分类:`、`文件:`） |

### 1.3 用户角色与权限体系

Fandom 的用户角色从低到高分为以下层级：

| 角色 | 权限范围 |
|------|----------|
| **未注册用户（匿名用户）** | 可阅读绝大多数页面，部分 Wiki 允许匿名编辑 |
| **注册用户** | 可编辑页面、上传文件、参与讨论 |
| **自动确认用户** | 注册满一定天数且编辑达一定次数后可移动页面、上传新文件 |
| **管理员（Admin）** | 可删除/恢复页面、封禁用户、保护页面、编辑 MediaWiki 命名空间 |
| **管理员（ bureaucrat）** | 拥有管理员全部权限，并可任命其他管理员 |
| **Fandom 职员（Staff）** | Fandom 官方工作人员，拥有所有 Wiki 的最高权限 |

**群组聊天（Chat）与讨论版（Discussions）** 也有独立的权限体系，由管理员配置。

## 二、内容创建流程

### 2.1 从零开始创建页面

1. **确认目标**：确定页面主题，搜索确认该页面是否已存在
2. **进入编辑**：点击页面右上角的"编辑"按钮，或在搜索框输入不存在的页面名后点击"创建此页面"
3. **选择编辑器**：可选择源代码编辑器或可视化编辑器
4. **编写内容**：使用 Wikitext 语法编写正文
5. **添加分类**：在页面底部添加 `[[分类:XXX]]` 归类
6. **预览检查**：使用预览功能确认显示效果
7. **填写编辑摘要**：简要描述本次修改内容（如"创建页面"、"修正笔误"）
8. **保存发布**：点击"保存更改"

### 2.2 编辑规范建议

- 每个页面的标题应唯一且含义清晰
- 首次创建时使用**小页面模式**，逐步扩充内容
- 善用**预览功能**避免语法错误
- 编辑摘要应当简洁明了，方便其他编辑者了解变更内容
- 遵循所在 Wiki 的风格指南（如有）

# 第二部分：Wikitext 编辑语法详解

## 三、编辑器模式

Fandom 提供两种编辑器，各有优劣：

| 编辑器 | 特点 | 适用场景 |
|--------|------|----------|
| **源代码编辑器** | 直接编写 Wikitext 源代码，功能最全 | 复杂格式、模板嵌套、高级语法 |
| **可视化编辑器** | 所见即所得（WYSIWYG），类似 Word | 简单文本编辑、新手入门 |

> **建议**：掌握源代码编辑器的使用是成为高效编辑者的关键。可视化编辑器在遇到复杂排版时往往无法精确控制效果，需要切换到源代码模式进行调整。

## 四、文本格式化

### 4.1 基本样式

| 效果 | Wikitext 语法 | 说明 |
|------|---------------|------|
| **粗体** | `'''粗体文本'''` | 使用三个英文单引号包裹 |
| *斜体* | `''斜体文本''` | 使用两个英文单引号包裹 |
| ***粗斜体*** | `'''''粗斜体'''''` | 使用五个英文单引号（三粗+二斜） |
| ~~删除线~~ | `<s>删除线</s>` | 使用 HTML `<s>` 或 `<del>` 标签 |
| 上标 | `<sup>上标</sup>` | HTML `<sup>` 标签 |
| 下标 | `<sub>下标</sub>` | HTML `<sub>` 标签 |
| `行内代码` | `<code>代码</code>` | HTML `<code>` 标签 |
| <u>下划线</u> | `<u>下划线</u>` | HTML `<u>` 标签 |
| 注释文本 | `<!-- 注释 -->` | HTML 注释，仅在源代码可见 |

**效果示例：**

```wikitext
'''洛疏律'''是一位茶客，身高''178CM''，体重''62KG''。
<s>以下内容已过时</s>
水的化学式是 H<sub>2</sub>O，圆的面积公式是 πr<sup>2</sup>。
使用 <code>mediawiki.api()</code> 方法可以调用 API。
```

**实际渲染效果：**

**洛疏律**是一位茶客，身高*178CM*，体重*62KG*。
<s>以下内容已过时</s>
水的化学式是 H₂O，圆的面积公式是 πr²。
使用 `mediawiki.api()` 方法可以调用 API。

### 4.2 段落与换行

| 操作 | 语法 | 说明 |
|------|------|------|
| 段落分隔 | 空一行 | 两个段落之间使用一个空行分隔 |
| 强制换行 | `<br>` | 在同一段落内换行，不产生段落间距 |

```wikitext
这是第一段落的内容，可以包含多行文字。
空行之后即开始新的段落。

这是第二段落的内容。
这是同一段落内的<br>换行效果。
```

## 五、标题与目录

### 5.1 标题语法

标题使用等号 `=` 包裹，**从二级标题开始**（一级保留给页面标题本身）：

```wikitext
== 一级标题 ==        <!-- 页面的主要章节 -->
=== 二级标题 ===       <!-- 章节下的子章节 -->
==== 三级标题 ====     <!-- 子章节下的细分 -->
===== 四级标题 =====   <!-- 更细分的层级 -->
====== 五级标题 ====== <!-- 最深层级 -->
```

**语法规则：**

- 标题必须从 `==`（二级）开始，不可使用 `=`（一级）
- 等号前后建议加一个空格，便于阅读
- 每个标题**独占一行**
- 标题内容不宜过长
- 同一页面中应避免标题名称重复（会导致锚点冲突）

### 5.2 目录控制

Fandom 会自动根据页面中的标题生成目录（Table of Contents，简称 TOC），默认放置在第一个标题之前。

使用**魔法字**控制目录行为：

| 魔法字 | 作用 |
|--------|------|
| `__TOC__` | 在插入位置手动放置目录 |
| `__NOTOC__` | 隐藏自动生成的目录 |
| `__FORCETOC__` | 强制在标题前显示目录（即使标题超过 4 个） |
| `__NOEDITSECTION__` | 隐藏每个标题旁的"编辑"链接 |

```wikitext
__NOTOC__        <!-- 本页不显示目录 -->
__TOC__          <!-- 在指定位置显示目录 -->

== 生平简介 ==
（内容...）

== 角色能力 ==
（内容...）
```

## 六、链接系统

链接是 Wiki 的核心功能，Fandom 支持多种链接类型。

### 6.1 内部链接

指向同一 Wiki 内其他页面的链接：

| 语法 | 显示效果 | 说明 |
|------|----------|------|
| `[[洛疏律]]` | 洛疏律 | 基本链接，显示为目标页面标题 |
| `[[洛疏律\|小律]]` | 小律 | 管道符 `|` 后为自定义显示文字 |
| `[[洛疏律#性格]]` | 洛疏律#性格 | 链接到页面内的指定章节（锚点） |
| `[[洛疏律#性格\|性格分析]]` | 性格分析 | 锚点链接 + 自定义显示文字 |
| `[[茶馆设定/角色列表]]` | 茶馆设定/角色列表 | 子页面链接（斜杠表示层级关系） |
| `[[wiki:帮助中心]]` | wiki:帮助中心 | 跨命名空间链接 |

**重要特性：**

- 内部链接中的**首字母不区分大小写**（Fandom 默认首字母大写）
- 空格会被自动转换为下划线 `_`
- 如果目标页面不存在，链接会显示为**红色**，提示可创建该页面

**示例：**

```wikitext
[[洛疏律]]是[[茶馆设定]]中的一位茶客。
更多角色请参见[[茶馆设定/角色列表|角色列表]]。
关于其性格分析，详见[[洛疏律#性格|性格特征]]。
```

### 6.2 外部链接

指向其他网站的超链接：

| 语法 | 显示效果 | 说明 |
|------|----------|------|
| `[https://example.com]` | [1] | 直接显示编号引用 |
| `[https://example.com 示例网站]` | 示例网站 | 自定义链接文字 |
| `https://example.com` | https://example.com | 直接输入 URL 自动转为链接 |

**示例：**

```wikitext
官方站点：[https://www.fandom.com Fandom官方网站]
更多信息请访问 https://community.fandom.com
```

### 6.3 跨语言链接

Fandom 支持通过跨语言链接关联同一主题的不同语言版本：

```wikitext
[[en:Luoshulv]]
[[ja:洛疏律]]
```

这些链接通常放在页面末尾，会在侧边栏的"其他语言"区域显示。

### 6.4 文件与分类链接

使用**冒号前缀**可创建指向文件描述页或分类页的普通链接（而非嵌入或归类）：

```wikitext
[[:文件:示例.jpg]]      <!-- 指向文件描述页的链接，而非嵌入图片 -->
[[:分类:人物]]           <!-- 指向分类页的链接，而非将页面归入该分类 -->
```

## 七、列表

### 7.1 无序列表

使用星号 `*` 表示，层级越多星号越多：

```wikitext
* 水果
* 茶饮
** 蜂蜜柚子茶
*** 热饮
*** 冷饮
** 茉莉柚茶
* 甜点
```

**渲染效果：**

- 水果
- 茶饮
  - 蜂蜜柚子茶
    - 热饮
    - 冷饮
  - 茉莉柚茶
- 甜点

### 7.2 有序列表

使用井号 `#` 表示，自动编号：

```wikitext
# 打开页面编辑器
# 填写内容
## 添加标题
## 插入图片
# 预览检查
# 保存发布
```

**渲染效果：**

1. 打开页面编辑器
2. 填写内容
   1. 添加标题
   2. 插入图片
3. 预览检查
4. 保存发布

### 7.3 混合列表

无序列表和有序列表可相互嵌套：

```wikitext
# 第一步：准备材料
#* 茶叶
#* 热水
#* 茶杯
# 第二步：冲泡
#* 温杯
#* 洗茶
#* 冲泡
```

**渲染效果：**

1. 第一步：准备材料
   - 茶叶
   - 热水
   - 茶杯
2. 第二步：冲泡
   - 温杯
   - 洗茶
   - 冲泡

### 7.4 定义列表

使用分号 `;` 定义术语，冒号 `:` 定义说明：

```wikitext
; 姓名
: 洛疏律
; 种族
: 人类
; 身高
: 178CM
; 特征
: 沉稳冷静，善于品茶
: 精通剑术
```

**渲染效果：**

- **姓名**
  - 洛疏律
- **种族**
  - 人类
- **身高**
  - 178CM
- **特征**
  - 沉稳冷静，善于品茶
  - 精通剑术

### 7.5 列表编写注意事项

- 列表项之间不要空行（空行会结束列表）
- 混合使用 `*` 和 `#` 时注意缩进层级一致
- 同一层级使用相同的标记符号

## 八、表格

表格是 Wikitext 中最具表现力的排版工具之一。

### 8.1 基本表格结构

```wikitext
{| class="wikitable"
|+ 表格标题（可选）
! 表头1 !! 表头2 !! 表头3
|-
| 行1列1 || 行1列2 || 行1列3
|-
| 行2列1 || 行2列2 || 行2列3
|}
```

**标记说明：**

| 标记 | 含义 |
|------|------|
| `{|` | 表格开始 |
| `|}` | 表格结束 |
| `|+` | 表格标题（可选，紧跟 `{|` 之后） |
| `!` | 表头单元格 |
| `|` | 普通单元格 |
| `||` | 同一行内分隔下一个单元格（也可用 `|` + 换行） |
| `|-` | 表格换行（开始新行） |

### 8.2 完整表格示例

```wikitext
{| class="wikitable" style="text-align: center; width: 80%;"
|+ 洛疏律个人资料
! 类别 !! 内容 !! 备注
|-
| 身高 || 178CM || 标准身材
|-
| 体重 || 62KG || 
|-
| 喜欢的茶 || 蜂蜜柚子茶 || 四季常饮
|-
| 技能 || 剑术、茶道 || 自幼修习
|}
```

### 8.3 表格高级用法

**合并单元格：**

```wikitext
{| class="wikitable"
! 项目 !! 数值
|-
| rowspan="2" | 身高体重 || 178CM
|-
| 62KG
|-
| colspan="2" | 注：数据来自官方设定集
|}
```

**渲染效果：**
（由于Astro和Fandom的语法差异，表格的样式可能会有差异）

| 项目 | 数值 |
|------|------|
| <div style="text-align:center;">**身高体重**</div> | 178CM |
| | 62KG |
| colspan="2" | 注：数据来自官方设定集 |

**设置单元格样式：**

```wikitext
{| class="wikitable"
! 角色
! style="width: 100px;" | 身高
! 特点
|-
| 洛疏律
| style="text-align: right;" | 178CM
| 沉稳
|-
| style="background: #f0f0ff;" | 洛疏律
| style="text-align: right;" | 165CM
| 温柔
|}
```

**可用的表格 class：**

| class 值 | 效果 |
|----------|------|
| `wikitable` | 标准 Wiki 表格样式（带边框和背景） |
| `wikitable sortable` | 可排序表格（点击表头排序） |
| `wikitable mw-collapsible` | 可折叠表格 |
| `wikitable mw-collapsed` | 默认折叠的表格 |

## 九、图片与媒体文件

### 9.1 插入图片

基本语法：

```wikitext
[[文件:文件名.jpg|参数1|参数2|...|说明文字]]
```

**常用参数组合：**

| 语法 | 效果 |
|------|------|
| `[[文件:示例.jpg]]` | 插入图片，使用原始大小（可能很大） |
| `[[文件:示例.jpg|thumb]]` | 缩略图样式，带边框 |
| `[[文件:示例.jpg|thumb|说明文字]]` | 缩略图 + 图片说明 |
| `[[文件:示例.jpg|thumb|300px|说明文字]]` | 缩略图 + 指定宽度 + 说明 |
| `[[文件:示例.jpg|thumb|right|300px]]` | 右对齐缩略图 |
| `[[文件:示例.jpg|frameless]]` | 无边框，原始大小 |
| `[[文件:示例.jpg|frameless|300px]]` | 无边框，指定宽度 |
| `[[文件:示例.jpg|center]]` | 居中对齐 |

**完整示例：**

```wikitext
[[文件:洛疏律.jpg|thumb|right|300px|洛疏律的官方立绘，由画师 XXX 绘制]]
```

**参数详解：**

| 参数 | 作用 |
|------|------|
| `thumb` / `thumbnail` | 启用缩略图样式（带边框和说明区域） |
| `frameless` | 无边框，但可指定尺寸 |
| `right` / `left` / `center` / `none` | 水平对齐方式 |
| `{宽度}px` | 指定图片宽度（如 `300px`），高度自动等比缩放 |
| `x{高度}px` | 指定图片高度（如 `x400px`），宽度自动等比缩放 |
| `{宽度}x{高度}px` | 同时限定宽高（如 `300x400px`） |
| `link={目标页面}` | 点击图片时跳转到指定页面而非文件描述页 |
| `alt={替代文本}` | 图片无法加载时显示的替代文字 |
| `border` | 为图片添加边框 |

### 9.2 图片画廊（Gallery）

使用 `<gallery>` 标签创建图片画廊：

```wikitext
<gallery>
洛疏律.jpg|立绘1
洛疏律_战斗.jpg|战斗姿态
洛疏律_日常.jpg|日常装束
</gallery>
```

**gallery 参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| `widths=` | 图片宽度（像素） | `widths=150` |
| `heights=` | 图片高度（像素） | `heights=120` |
| `perrow=` | 每行图片数 | `perrow=4` |
| `caption=` | 画廊标题 | `caption=角色图鉴` |

```wikitext
<gallery widths="150" heights="150" perrow="3" caption="角色图鉴">
洛疏律.jpg|洛疏律
1.jpg|1
2.jpg|2
</gallery>
```

### 9.3 嵌入视频与音频

**YouTube 视频：**

```wikitext
<youtube>https://www.youtube.com/watch?v=VIDEO_ID</youtube>
```

**Vimeo 视频：**

```wikitext
<vimeo>https://vimeo.com/VIDEO_ID</vimeo>
```

**音频文件（使用 `[[文件:]]` 语法）：**

```wikitext
[[文件:配乐.ogg]]
[[文件:音效.mp3]]
```

## 十、引用与脚注

引用系统用于标注信息来源或添加补充说明。

### 10.1 行内引用

在引用内容后添加 `<ref>` 标签：

```wikitext
洛疏律身高178CM<ref>出自茶客设定</ref>，体重62KG<ref>同上</ref>。
```

### 10.2 显示参考文献

在页面末尾使用 `<references />` 自动列出所有引用：

```wikitext
== 参考文献 ==
<references />
```

### 10.3 命名引用（复用）

对同一来源的多次引用使用命名引用，避免重复：

```wikitext
洛疏律是一位茶客<ref name="background">1</ref>。
2<ref name="background" />。
```

## 十二、模板

模板是 Fandom 最强大的功能之一，用于封装可复用的内容片段。

### 12.1 模板的基本调用

```wikitext
{{模板名}}                     <!-- 无参数调用 -->
{{模板名|参数值}}              <!-- 单一参数 -->
{{模板名|参数1|参数2|参数3}}    <!-- 多个匿名参数 -->
{{模板名|参数名=参数值}}        <!-- 命名参数 -->
```

### 12.2 模板的完整使用示例

假设 Wiki 中存在模板 `角色信息框`：

```wikitext
{{角色信息框
| 姓名    = 洛疏律
| 图像    = 洛疏律.jpg
| 身高    = 178CM
| 体重    = 62KG
| 种族    = 人类
| 年龄    = 24岁
| 职业    = 茶客
| 喜好    = 蜂蜜柚子茶、剑术
}}
```

### 12.3 常用系统模板（未实装）

| 模板 | 说明 |
|------|------|
| `{{清除}}` | 清除浮动（`<div style="clear:both;"></div>`） |
| `{{Color|颜色代码|文字}}` | 设置文字颜色，如 `{{Color|red|红色文字}}` |
| `{{引用|来源}}` | 插入引用格式文本 |
| `{{注|注释内容}}` | 插入注释 |
| `{{失效链接}}` | 标记已失效的外部链接 |
| `{{需要更新}}` | 标记需要更新的页面段落 |
| `{{剧透警告}}` | 剧透内容提示 |
| `{{Stub}}` | 标记页面为小作品（待扩充） |
| `{{Delete}}` | 标记页面需要删除 |

### 12.4 模板参数说明

模板参数有两种传递方式：

| 方式 | 语法 | 适用场景 |
|------|------|----------|
| **匿名参数** | `{{模板|值1|值2|值3}}` | 参数顺序固定，数量少 |
| **命名参数** | `{{模板|参数名=值}}` | 参数数量多，可读性强，可省略可选参数 |

## 十五、重定向

重定向用于将一个页面自动跳转到另一个页面。

### 15.1 基本重定向

```wikitext
#redirect [[目标页面名称]]
#重定向 [[目标页面名称]]
```

### 15.2 带片段的重定向

```wikitext
#redirect [[洛疏律#性格]]
```

### 15.3 使用说明

- 重定向指令必须放在页面**最开头**，前面不能有任何内容
- 重定向页面会保留版本历史，不会被删除
- 访问重定向页面时会自动跳转到目标页面，并显示"重定向自 XXX"的提示
- 如果要覆盖重定向，直接编辑该页面修改内容即可
- 中英文 `#redirect` 和 `#重定向` 均可使用

## 十六、分类与标签

分类是 Fandom 组织内容的基石。

### 16.1 为页面添加分类

```wikitext
[[分类:人物]]
[[分类:茶馆设定]]
```

### 16.2 指定分类排序

使用管道符 `|` 指定在分类页面中的排序名称：

```wikitext
[[分类:人物|洛疏律]]
[[分类:茶馆设定|洛]]
```

如果不指定排序名称，默认按页面标题排序。指定排序可以控制同一分类中各页面的排列顺序。

### 16.3 分类的注意事项

- 分类通常放在页面**末尾**
- 同一页面可属于多个分类
- 分类本身也是一个页面，可以编辑其描述文字
- 分类可以嵌套（如 `分类:角色` 下包含 `分类:主角` 和 `分类:配角`）
- 使用 `[[:分类:人物]]`（冒号前缀）可创建指向分类页的普通链接

### 17.1 块级标签

|------|------|---------------|

- 内联样式（`style="..."`）使用 CSS 属性，建议使用 class 类名

## 十八、高级功能

### 18.1 解析器函数（Parser Functions）

解析器函数是以 `#` 开头的特殊模板调用，用于实现条件判断、字符串处理等逻辑。

**条件判断：**

```wikitext
{{#if: {{{参数|}}} | 参数存在时显示 | 参数不存在时显示 }}
{{#ifeq: 值1 | 值2 | 相等时显示 | 不相等时显示 }}
{{#ifexpr: 1 > 0 | 真时显示 | 假时显示 }}
```

**示例：**

```wikitext
{{#ifeq: {{PAGENAME}} | 洛疏律 | 这是茶客页面 | 这是其他页面 }}
```

**选择分支：**

```wikitext
{{#switch: {{PAGENAME}}
| 洛疏律 = 欢迎来到茶客页面
| 茶馆设定 = 这是世界观页面
| #default = 其他页面
}}
```

### 18.2 字符串处理

```wikitext
{{#len: 字符串}}              <!-- 返回字符串长度 -->
{{#sub: 字符串 | 起始位置 | 长度 }}  <!-- 截取子串 -->
{{#pad: 5 | 3 | 0 }}          <!-- 填充为 005 -->
{{lc: 大写转小写}}              <!-- 转换为小写 -->
{{uc: 小写转大写}}              <!-- 转换为大写 -->
```

### 18.3 URL 处理

```wikitext
{{#urlencode: 查询参数}}          <!-- URL 编码 -->
{{#anchorencode: 章节标题}}       <!-- 锚点编码 -->
{{fullurl: 页面名}}               <!-- 生成完整 URL -->
{{fullurl: 页面名|action=edit}}   <!-- 生成编辑链接 -->
```

### 18.4 命名空间检测

```wikitext
{{#if: {{NAMESPACE}} | 当前在 {{NAMESPACE}} 命名空间 | 当前在主命名空间 }}
```

### 18.5 扩展标签

Fandom 支持丰富的扩展标签，用于嵌入外部内容：

| 标签 | 用途 | 示例 |
|------|------|------|
| `<gallery>` | 图片画廊 | `<gallery>文件1.jpg|说明</gallery>` |
| `<youtube>` | 嵌入 YouTube 视频 | `<youtube>VIDEO_ID</youtube>` |
| `<vimeo>` | 嵌入 Vimeo 视频 | `<vimeo>VIDEO_ID</vimeo>` |
| `<spotify>` | 嵌入 Spotify 音乐 | `<spotify>TRACK_ID</spotify>` |
| `<twitter>` | 嵌入推文 | `<twitter>STATUS_ID</twitter>` |
| `<mapframe>` | 嵌入地图 | `<mapframe>经纬度</mapframe>` |
| `<timeline>` | 创建时间线 | `<timeline>...</timeline>` |
| `<ref>` | 引用/脚注 | `文本<ref>来源</ref>` |
| `<references>` | 引用列表 | `<references />` |

## 十九、常见问题与调试技巧

### 19.1 语法不生效的常见原因

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 粗体/斜体没效果 | 引号数量不对 | 检查是否使用了准确的 2 或 3 个单引号 |
| 链接显示为红色 | 目标页面不存在 | 确认页面名拼写，或创建该页面 |
| 链接显示为普通文字 | 被 `<nowiki>` 包裹 | 检查周围是否有 nowiki 标签 |
| 表格错乱 | 管道符 `|` 缺失 | 检查每行单元格分隔符 |
| 模板显示为 `{{...}}` | 模板不存在 | 确认模板名称拼写 |
| 图片显示为链接 | 忘记加 `文件:` 前缀 | 检查 `[[文件:]]` 语法 |
| 分类未生效 | 放在页面中间而非末尾 | 将分类移至页面底部 |
| 标题不生成目录 | 使用了 `__NOTOC__` 或标题不足 4 个 | 移除 `__NOTOC__` 或使用 `__FORCETOC__` |
| 重定向不生效 | 指令前有空格或其他内容 | 确保 `#redirect` 在页面第一行 |

### 19.2 调试方法

1. **使用预览功能**：在保存前预览，可即时发现语法错误
2. **逐步排查**：当页面出现异常时，逐段移除内容定位问题
3. **查看源代码**：学习已有页面的 Wikitext 写法，复制成功模式
4. **查看差异**：比较不同版本间的差异，了解修改的影响
5. **沙盒测试**：在个人沙盒页面中测试复杂语法

### 19.3 高效编辑技巧

- 使用 **搜索并替换** 批量修改同类内容
- 善用 **复制粘贴** 模板调用，避免重复输入
- 常用代码片段可保存为个人模板
- 使用 **编辑摘要** 标记编辑类型（如"小修改"）
- 大段编辑建议先复制到本地文本编辑器，防止意外丢失

## 二十、Markdown 与 Wikitext 语法对照

对于熟悉 Markdown 的编辑者，下表可帮助快速对照学习：

| 效果 | Markdown 语法 | Wikitext 语法 |
|------|--------------|---------------|
| **粗体** | `**文本**` | `'''文本'''` |
| *斜体* | `*文本*` | `''文本''` |
| ~~删除线~~ | `~~文本~~` | `<s>文本</s>` |
| 标题 | `# 标题` | `== 标题 ==` |
| 内部链接 | `[文字](链接)` | `[[页面名\|文字]]` |
| 外部链接 | `[文字](https://...)` | `[https://... 文字]` |
| 图片 | `![描述](url)` | `[[文件:名.jpg\|thumb\|说明]]` |
| 无序列表 | `- 项目` | `* 项目` |
| 有序列表 | `1. 项目` | `# 项目` |
| 代码块 | ` ``` ` 包裹 | `<syntaxhighlight>` 包裹 |
| 行内代码 | `` `代码` `` | `<code>代码</code>` |
| 引用块 | `> 引用` | `<blockquote>引用</blockquote>` |
| 表格 | 管道符 + 短横线 | `{|` + 管道符 + `\|}` |
| 水平线 | `---` | `<hr>` 或 `----` |
| 脚注 | `[^1]` | `<ref>` 标签 |
